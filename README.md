# Youssef Issaoui Portfolio

Static portfolio for three published mobile apps.

## Open

Open `index.html` directly in a browser.

## Update Projects

Edit `portfolio.config.js`.

- Add mobile apps inside the `apps` array.
- Put app icons or screenshots inside `assets/` and reference them with `image`.
- Use a store URL for live apps or a `status` value such as `Soon` for upcoming iOS listings.

The page renders app cards automatically from the config file, so the layout does not need to be edited every time the app links change.
